# Task Patterns

Learned task execution patterns.

## LinkedIn recruiter sweep

- Initial outreach: send specific info-request (day-to-day responsibilities, compensation range, contract type/duration, remote policy) in recruiter's language, not generic "tell me more"
- Follow-up handling: when recruiter replies to initial info-request with job posting URL, auto-generate qualified response using job posting content
- Qualified response: surface draft in Slack for approval before sending (not auto-send)
- Resume attachments: LinkedIn script does not support file attachments; must attach PDFs/text manually via LinkedIn UI
