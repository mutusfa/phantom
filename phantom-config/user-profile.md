# User Profile

Preferences, habits, and corrections learned from interactions.

- When asking to run/check something, expects it to be done as specified rather than sampled or explored first
- Pushes back on excessive tool calls or exploration when registered tools are ready to use
- Prefers agent to use `run_in_background: true` on Bash tool for >1min jobs instead of shell `&` fire-and-forget
- For recruiter outreach, prefers specific info requests (day-to-day responsibilities, compensation range, contract type, remote policy) over generic "tell me more"
- When scheduling interviews, values framing Azure experience as equivalent to AWS (both are cloud data platforms)
- Expects agent to trust available tools rather than inspect/explore them first
